TESTSIEGER SCHWEIZ – PWA

Dateien gemeinsam auf einen HTTPS-Webspace hochladen:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

Wichtig: Nicht index.html allein per SharePoint-Vorschau öffnen. Eine PWA benötigt eine echte HTTPS-Website oder localhost.

Test: URL in Chrome auf Android öffnen. Danach Menü > App installieren bzw. Zum Startbildschirm hinzufügen.
